# Todo List with LocalStorage | لیست یادداشت‌ها

A simple, clean, and fully functional To-Do List application built with Vanilla JavaScript. It allows users to add and delete notes, and saves all data in the browser's `localStorage` so the data persists even after refreshing the page.

یک اپلیکیشن ساده و کاربردی برای مدیریت یادداشت‌ها که با استفاده از HTML، CSS و جاوااسکریپت خالص (Vanilla JS) ساخته شده است. داده‌ها در `localStorage` مرورگر ذخیره می‌شوند و با رفرش صفحه از بین نمی‌روند.

---

## Features | ویژگی‌ها

- **Add Tasks:** Quickly add new notes to the list.
- **Delete Tasks:** Remove unwanted notes with a single click.
- **Persistent Storage:** Uses `localStorage` and `JSON.stringify/parse` to save data locally.
- **Responsive & Clean UI:** Styled with modern CSS (Flexbox) and uses the Vazirmatn font for beautiful Persian typography.
- **Empty State Validation:** Prevents adding empty notes.

- **افزودن یادداشت:** امکان اضافه کردن سریع یادداشت جدید.
- **حذف یادداشت:** حذف آیتم‌ها با یک کلیک.
- **ذخیره‌سازی دائمی:** استفاده از `localStorage` و تبدیل JSON برای جلوگیری از پاک شدن داده‌ها با رفرش صفحه.
- **رابط کاربری زیبا:** استفاده از Flexbox برای چیدمان و فونت وزیرمتن برای تایپوگرافی فارسی.
- **اعتبارسنجی:** جلوگیری از اضافه شدن یادداشت خالی.

---

## Technologies Used | تکنولوژی‌های استفاده شده

- **HTML5** (Semantic Structure)
- **CSS3** (Flexbox, Transitions, Custom Properties)
- **JavaScript (ES6+)**
  - DOM Manipulation
  - Array Methods (`forEach`, `splice`, `push`)
  - `localStorage` API
  - `JSON.stringify()` & `JSON.parse()`
